### 🚀 What I do

Every day I pick **one real-world problem** people around me are actually facing — smog season, dengue outbreaks, unfair rents, grocery overcharging, youth unemployment — design a complete UX case study for it, **and build the working website**. No mockups-only portfolio: every project below has a live demo you can open and use.

- 🎓 BS Computer Science (3rd semester), **UET Peshawar**, Pakistan
- 🎨 Design: Figma — research, personas, wireframes, design systems, hi-fi UI
- 💻 Code: semantic HTML, modern CSS, vanilla JavaScript — no frameworks, everything hand-built and readable
- 🎬 I also run **Abbas Music World**, a traditional Pashto folk-song channel on YouTube
